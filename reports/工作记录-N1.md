## 2 数据获取

官方页面是 Drupal 动态页，`.mat` 直链形如
`https://engineering.case.edu/sites/default/files/{id}.mat`，无需登录。真实难点是**文件号与工况的映射**，官方表格必须逐行解析，不能凭记忆或二手清单。

做法：写 HTMLParser 解析三张表（normal / 12k DE / 48k DE），只取 12k DE 与 normal，落到 `configs/cwru_manifest.csv`。解析结果纠正了三处：

| 二手清单常见写法 | 官方表格实际 |
|---|---|
| `IR021_3 = 212.mat` | **217.mat**（212 文件也在，但表格不指向它） |
| `OR007@12_1 = 157.mat` | **158.mat**（157 未列出） |
| 外圈 0.014″ 有 3 点/12 点 | 只有 6 点钟（`*` 缺失） |

下载本身不快：单连接约 40 KB/s，10 并发聚合 ~100–300 KB/s，208 MB 用了 23 分钟。中间换过一次并发实现（见坑 3）。

## 3 特征设计中的两个关键决定

### 3.1 窗长 1024 → 2048

最初按常见做法用 1024 点（85 ms）。在真实数据上抽查时发现 `env_bpfi_h1_snr` 在 106/170/171/172/210 上**恒为 0**。

原因不是数据没有内圈故障，而是：包络谱分辨率 Δf = fs/N = 11.7 Hz，而 BPFI 的 ±2% 带宽只有 ±3.2 Hz，**带宽窄于一个频率单元，带内可能一个 bin 都没有**，代码里 `if m.any() else 0.0` 就静默给了 0。

修复两条一起做：
- 带宽改为 `max(2%·fc, Δf)`，保证至少落进一个 bin；
- 窗长提到 2048（Δf=5.86 Hz），兼顾分辨率与样本量。

修复后内圈文件的 BPFI 明显高于 BPFO（4.0–5.4 vs 3.4–3.6），正常件两者打平（~2.7），物理上讲得通。这条如果没抽查，整组包络特征会带着 40% 的假零值进模型，而且不会报错。

### 3.2 为什么坚持用实测 RPM

`.mat` 里带 `X###RPM`。所有阶次特征都用实测转速换算，不用载荷标称值（1797/1772/1750/1730）。理由：同一载荷下不同文件的实测转速能差 5–10 rpm，而 BPFO 的 1% 就是 1 Hz 量级；用标称值会在高阶谐波上累积误差。

代价：这套特征依赖转速可得。报告 §5 明确写了这个边界。

## 4 实验过程中发现的异常

### 4.1 留一载荷 3 HP 折突然掉到 0.747

第一反应是"跨载荷迁移失败"。但逐文件打印后发现：**只有 217.mat 错，且 478 个窗口全部判成滚动体**，其余 9 个文件（含正常、外圈、滚动体、另外两个内圈）全对。

查证据：

| 项 | 217 | 同组其他 | 结论 |
|---|---|---|---|
| 转速 | 1752 rpm | 1721 / 1728 | 属 2 HP 档 |
| 时长 | 41.0 s | 10.1–10.2 s | 不同录制批次 |
| RMS | 0.760 | 内圈全体 0.143–0.569 | 超出上界 |
| 峭度 | 3.50 | 内圈全体 4.86–35.46 | 低于下界 |
| BPFI−BPFO | −0.63 | 内圈全体 −0.16…+2.47 | 唯一 BPFO 主导 |

处理：保留文件、在报告里给含/剔两套数字、在 `download_log.json` 里留 sha256。**没有删**——它是官方表格指向的文件，删了等于改数据集定义。

### 4.2 消融结果反常：全特征 0.924 < 仅包络 0.993

一开始以为是缓存串了。查证后确认是真结果：同一折、同一 SVM，仅包络特征把 217 的 461/478 判成内圈（acc 0.982），全特征把 478/478 判成滚动体（0.747）。机制是时域幅值特征把 217 推出内圈簇。

这条反过来成了报告里最有价值的一条工程结论：**特征不是越多越好，幅值类特征在跨工况时是负担**。

### 4.3 加噪实验推翻了自己的预期

原本预期"物理特征比 CNN 抗噪"。实测相反：10 dB 下特征模型 0.545，CNN 0.985。查了特征分布：谱熵 0.849→0.924（约 1.3σ，且方差从 0.057 压缩到 0.010），包络 BPFO 信噪比 3.53→2.71。是训练-测试分布错位，不是信号被淹没。报告按实测写，没有为了叙事好看而弱化。

## 5 踩过的实现坑

1. **`/tmp` 在 Windows 上不是 Git Bash 的 `/tmp`**：Python 里写 `/tmp/xxx` 会找不到文件。统一改用 `C:/Users/.../AppData/Local/Temp` 或仓库内相对路径。
2. **`config.load_config()` 返回 dict，不是对象**：第一版下载脚本写了 `cfg.raw_path`，AttributeError。
3. **串行下载 40 KB/s**：64 个文件要一个多小时。改成 `ThreadPoolExecutor` 10 并发后聚合 ~100–300 KB/s；注意先写 `.part` 再原子替换，否则中断会留下半文件。
4. **`02_train_classical.py` 里 `FEATURE_NAMES` 的作用域**：在 `main()` 里赋值是局部变量，`run_protocol()` 里读会 NameError。改成显式传参。
5. **特征缓存键不含数据规模**：`features_{groups}_w{window}.npz` 先跑 main（6246 窗）再跑全量（9063 窗）会读错缓存。维度不同时会报 IndexError，**维度恰好相同就会静默出错**。键里加 `n{len(ws)}`。
6. **`_agg` 与 `_agg_folds` 混用**：跨折汇总时把 fold 字典当 metrics 字典传给 `_agg`，KeyError: 'accuracy'。拆成两个函数。

### 7.2 三个新结论

1. **噪声增广推翻了 v1.0 的"特征怕噪"**：增广后 SVM_all 在 10 dB 从 0.545 回到 1.000，−4 dB 仍有 0.990。崩溃是训练分布问题，不是特征方法固有缺陷。
2. **CNN 不外推损伤尺寸**：0.028″ 上 934 窗全判 IR（0.500），与 RF 0.493 一起塌；只有 SVM 0.874 有部分外推。
3. **位置 few-shot：特征模型 48 窗就够，CNN 重训不行、微调头才对**：SVM 0.265→0.998；CNN 重训 0.32–0.56 非单调（被主线窗口淹没）；冻结骨干微调 head 后 2.5% 起全部 1.000。

### 7.3 v1.1 踩的坑（新增）

7. **`carve_val` 会吃掉 few-shot 窗口**：目标文件只有几个时间块，`max(1, ...)` 的验证集切分会把小比例适配集**整块**划进验证集——2.5%/5% 两档的曲线与零样本完全相同才发现。修法：验证集只从主线文件切，适配窗口全部留在训练集。**教训：适配/迁移实验里，验证集不能从目标域切。**
8. **两个后台任务并发写同一份结果**：重启实验时旧进程没杀干净，两个 `09_cnn_ood.py` 同时写 log/JSON。修法：启动前查 `Win32_Process` 清残留，重启链式任务。
9. **GitHub 推送走代理时好时坏**：`api.github.com` 与 `github.com` 的 502 交替出现；git push 与 REST API 都要带重试。仓库用 API 建、代码用 git push 推（分支名 `master` 需先改 `main`）。

### 8.2 四个新结论（都推翻或收紧了既有表述）

1. **217 的训练侧效应与测试侧相反，且剂量敏感**：测试侧 −25 点；训练侧 3→0 +0.097；B3 去混杂证明不是数据量（upsample 全平）而是分布桥接，且 117 窗小剂量（0.986）好于全量 478 窗（0.948）。
2. **"仅包络最强"是 SVM 特有的**：RF 在 LOO 上时域 0.959 最强、仅包络 0.907 最弱。§3.3 原表只测了 SVM，差点写成通用结论。
3. **阶次化没有消掉载荷信息**：载荷探针仅包络 77%、全特征 89%（机会 25%）。§4.1 原解释只对了频率缩放那一半；真正的机理是多源训练把载荷方向学成不变量。
4. **10 分类错误结构 = 错部位不错尺寸**：尺寸误差从不跨档（≤1 档 1.0000），部位对则尺寸对 0.986–0.999；LOO 的部位错误几乎全是 217（IR021 召回 0.424/0.544）。

### 8.3 踩的坑

10. **工厂函数签名错配**：`_svm(cfg, seed)` 定义成双参，却按 `factory(seed)` 单参调用，`cfg["classical"]` 下标打到 int 上。教训：实验脚本的模型工厂统一用 `lambda seed: ...` 闭包，别做"半柯里化"。
11. **布尔掩码装不下重采样**：upsample 条件有放回采样会出重复索引，`np.isin`/掩码会去重、样本数静默对不上。训练索引含重复样本时必须走索引数组。
12. **matplotlib 缺字形**：标题里的 `≫` 在 Microsoft YaHei 里缺 glyph 只出框。中文标题避开数学符号。
